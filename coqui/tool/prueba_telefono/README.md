# prueba_telefono

Order 00 of the Flutter move (docs/proyecto/13-flutter-orders.md): a throwaway phone test page. Web only,
standalone (not part of the coqui workspace). `./publish.sh` builds it and copies the build to `prueba/` at
the repo root. Open `prueba/?sem=1` to turn on Flutter's semantics tree (scripts tap the buttons through it).
